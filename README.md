# CodeAlpha_Sentiment_Analysis

## Project Overview
This project performs Sentiment Analysis on customer reviews using Python and TextBlob.

## Features
- Classifies reviews as Positive, Negative, or Neutral
- Uses TextBlob for sentiment analysis
- Displays results in a structured table using Pandas

## Sample Reviews
- This product is amazing
- I love this phone
- The service was very bad
- Not satisfied with the quality
- Excellent experience
- Worst product ever

## Tools Used
- Python
- Pandas
- TextBlob
- Jupyter Notebook

## Output
The program analyzes reviews and predicts their sentiment.
